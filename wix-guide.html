0 · אסטרטגיית "בנייה במקביל" — בלי לסכן את הקיים

  1. ב-Wix Studio / החשבון הקיים: Site actions ← Duplicate site על האתר הקיים, או צור אתר חדש ריק. קרא לו Kfar Silver NEW 2026.
  2. עובדים רק על העותק החדש. האתר החי לא נוגעים בו בכלל.
  3. לתצוגה להנהלה בלי לפרסם: כפתור Preview, או Share ← Get feedback link (לינק צפייה זמני שוויקס נותן בלי דומיין).
  4. רק אחרי אישור סופי: Publish ואז העברת הדומיין kfarsilver.com לאתר החדש (Settings ← Domains ← Assign). מרגע זה הישן יורד — שומרים אותו כגיבוי בחשבון.
⚠️ קריטי — המשכיות מדידה: באתר החדש חובה לשמר את אותם נתיבי עמודי תודה (/תודה-על-ההרשמה-פנימייה) או לעדכן את הטריגר ב-GTM ביום ההחלפה. אחרת מעקב ההמרות של גוגל אדס (שתיקנו ועובד!) יישבר. וגם: להתקין באתר החדש את אותו GTM — ראה סעיף 8.

4 · תפריט, פוטר וכפתורים צפים

  • Header: לוגו מימין, תפריט במרכז, כפתור ליים "הרשמה לסיור" + מתג RU משמאל. מסמנים Fixed/Sticky כדי שיישאר צמוד למעלה.
  • פוטר: רקע סגול עמוק, 4 עמודות (זהות להדמיה) + שורת © עם שנה נוכחית — לתקן את ה-"© 2020" הקיים!
  • וואטסאפ צף: Add ← Contact & Forms ← WhatsApp button, מספר 972545090835, מיקום פינה שמאל-תחתון.
  • צ'אט/בוט: Add Apps ← Wix Chat. תחת Settings ← Saved Replies מזינים את 10 השאלות הנפוצות (מעמוד השו"ת) ← Automated ← Welcome message: "היי! על מה תרצו לשמוע? קבלה / עלויות / יום בפנימייה". מפעילים ניתוב לוואטסאפ כשאין מענה.

5 · טפסים — ההגדרה המדויקת

טופס ראשי (ראשי + צור קשר)

Add ← Contact & Forms ← בוחרים טופס בסיסי ← עורכים שדות:

  1. שם ההורה — Short text, חובה
  2. שם הילד/ה — Short text, רשות
  3. טלפון — Phone, חובה
  4. אימייל — Email, רשות (בעמוד צור קשר בלבד)
  5. עולה לכיתה — Dropdown: ז׳/ח׳/ט׳/י׳/יא׳
  6. מה מעניין אתכם — Dropdown: פנימייה / בית ספר / נעל"ה / אחר (צור קשר בלבד)
  7. הסכמת וואטסאפ — Checkbox, רשות ולא חובה!
⚠️ הלקח מהבדיקה שעשינו: באתר הנוכחי צ'קבוקס הוואטסאפ מוגדר חובה — טופס בלעדיו פשוט לא נשלח, וזה מפיל לידים. בחדש: רשות. מי שלא סימן — מתקשרים.

הגדרות שליחה (בכל טופס: Settings ← Submission)

  1. After submit ← Redirect to page: עמוד התודה /תודה-על-ההרשמה-פנימייה — זה מה שמפעיל את המרת גוגל אדס!
  2. Email notifications: למייל של צוות הקליטה + שלך.
  3. הטופס הרוסי — עותק מתורגם, עם עמוד תודה משלו /spasibo.

7 · מוכנות לחיפוש AI — מה שהדוח דרש

  • שו"ת ב-Accordion של Wix — ויקס מזריק אוטומטית FAQ Schema (מבנה נתונים שמנועי AI קוראים). לכן חובה להשתמש ברכיב FAQ ולא בטקסט רגיל.
  • כל תשובה = תשובה מלאה (2-4 משפטים עם מספרים), לא "צרו קשר לפרטים".
  • בלוג (Add Apps ← Wix Blog): לפחות פוסט בחודש — מהפודקאסט המצולם יש חומר מוכן. עמוד "חדשות" מציג את הפיד.
  • SEO לכל עמוד: Pages ← SEO Basics ← Title בפורמט "הפנימייה | כפר הנוער סילבר" + Description של משפט-שניים עם המספרים.

8 · מדידה — לא לשכוח ביום ההחלפה

  1. באתר החדש: Settings ← Custom Code ← להדביק את קוד GTM GTM-WNSHJF5K (Head + Body) — בדיוק כמו בקיים.
  2. לוודא שעמוד התודה בנתיב זהה לקיים. אם משנים — לעדכן את הטריגר ב-GTM באותו יום.
  3. אחרי ההחלפה: להריץ את אותה בדיקת טסט שעשינו (טופס "טסט") ולוודא ששני פינגי ההמרה נורים.

9 · סדר עבודה מוצע

  1. שבוע 1: הקמת אתר עותק, סיסטם דיזיין (סעיף 1), עמוד ראשי מלא.
  2. שבוע 2: שאר העמודים + טפסים + אוטומציות. שליחת לינק Preview להנהלה + ההדמיה הזו.
  3. שבוע 3: סבב תיקוני הנהלה, השלמת טקסטים חסרים (מסומנים [ להשלמה ] בהדמיה), צילומים ועדויות.
  4. יום ההחלפה: Publish ← העברת דומיין ← בדיקת GTM וטופס ← מעקב יומיים.
